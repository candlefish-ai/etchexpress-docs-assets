# Etch Express — help centre image assets

Screenshots referenced by articles in the Etch Express help centre
(<https://help.etchexpress.ai>).

This repository is public for one reason: Intercom has no image upload API. It
ingests images only by fetching a public URL, then rehosts them on its own CDN.
These files therefore need to be publicly reachable at the moment an article is
pushed. Nothing here is sensitive — every image is already published on the
public help centre.

Captured from the app with demo data. No customer information appears in any image.
